    In addition, the developer must specify how the incoming request data is mapped to the integration request and how the resulting integration response data is mapped to the method response. 

    Answer. HTTP is the most suitable integration types. 

        - You can integrate an API method in your API Gateway with a custom HTTP endpoint of your application in two ways. 
        - HTTP Proxy Integration
        - HTTP Custom Integration

        - Proxy Integration, the setup is simple. You only need to set the HTTP method and the HTTP endpoint URI, according to the backend requirements, if you are not concerned withh content encoding or caching. 
        - HTTP Proxy integration and HTTP integration, the value is HTTP_Proxy and HTTP, respectively. 
        - Since the integration type that is being describe in the senario fit sthe definiton of an HTTP custom integration, the correct answer is to use the HTTP integration type. 

        - HTTP Proxy is incorrect because this type is only used for HTTP proxy integration when you don't need to do data mapping for your request and response data. 

    Summary: Proxy Integration, the setup is simple. You only need to set the HTTP method and the HTTP endpoint URI

It is required to run large nodes with multiple cores for a cache layer, and it should scale up or down as the demand ont he system increases and decreases. 

    Answer: Amazon ElastiCache for Memcached

    Redis and Memcached are popular, open-source, in-memory data stores. Although thhey are both easy to use and offer high performance, there are important differences to connsider when choosing an engine. 
        - Memcached is designed for simplicity, while Redis offers a rich set of features that make it effect for a wide range of use cases. 
        - Redis can provide more durable and powerful cache layer to the prototype distributed system; however, you should take note on one keyword in the requirement:
            
            Multithreaded. 

            Redis is mostly a singly-threaded server. It is not designed to benefit from multiple CPU cores, unlike Memcached; however, you can launch several Redis instances to scale out on several cores if needed. 

            Memcached is more suitable since the scenario specifies that the system will run large notdes with multiple cores or threads, which Memcached can adequately provide.

                - You need to run large nodes with multiple cores or threads
