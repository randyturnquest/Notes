AWS Security Token Service is a global web service that allows you to generate temporary access for IAM users for federated users to gain access to your AWS resources. 
    - These temporary crednetials are session-based, meaning they're for short term use only; once expired they can no longer be used to access your AWS resources. 

Assume Role API - Once a request is successful, AWS generates and returns temporary credentials consisiting of an access key ID, a secret access key, and a security token. These crednetials can be usedd by the IAM user to make requests to AWS services. 

STS AssumeRoleWithWebIdentity does not require IAM Identity credentials, making it suitable for mobile applications that require access to AWS. It is recommended that you use Amazon Cognito when providing AWS access to application users. However, you may just use AssumeRoleWithWebIdentity as a standalone operation.   

STS API Operations - GetFederationToken operation that returns a set of temporary security credentials consisting of a security token access key, secret key, and expiration for a federated user. 

GetFederationToken is usually used for federating access to users authenticated by a custom identity broker and can only be called using programmatic crednetials of an IAM user. IAM Roles are not supported.

Although you can use the security crednetials of a root user to call GetFederationToken it is not recommend for security reasons
    - Instead AWS advises creating an IAM user specifically for a proxy application that does the authentication process. 

You can use the temporary GetFederationToken in any AWS service except the following
    - IAM Operations
    - STS Operations
